# الميزات والحدود الفنية

## موجود في الكود
- Laravel 13، بنية مرتبة ومفصولة Controllers / Models / Migrations / Blade.
- واجهة تصميم احترافية ومتجاوبة، دعم عربي/إنجليزي.
- العقارات: CRUD كامل، صور رئيسية ومتعددة، أسعار، أنواع، معالم ومرافق، حالات النشر، موقع جغرافي واختيار وكيل.
- صفحات عامة: البحث والتصفية وفرز النتائج، تفاصيل العقار، صفحات الأحياء، حفظ العقارات في الجلسة، المدونة، اتصل بنا، صفحات CMS.
- CRM: استقبال استفسارات، تحديد الحالة، ملاحظات متابعة، إسناد للمستخدمين، طلبات مشاهدة.
- عقود: إضافة وتعديل وتتبع سجل عقد بيع/إيجار؛ سجل يدوي للدفعات وحالتها.
- إدارة المقالات والوكلاء والمستخدمين الإداريين والإعدادات والصفحات.
- أدوار Admin و Agent؛ الوكيل يصل إلى عقاراته والسجلات التابعة لها.
- API عام للقراءة `GET /api/v1/properties` و `GET /api/v1/properties/{slug}`، ولا يعرض المسودات.
- حماية CSRF في النماذج، تحقق من المدخلات، قيود على رفع الصور، قيود معدلات على الاستفسارات وتسجيل الدخول.
- Sitemap آلي ووسوم SEO أساسية.

## تكاملات إضافية غير موجودة في النسخة
- معالجة دفع حقيقية، فواتير ضريبية معتمدة، توقيع إلكتروني قانوني أو إدارة ضمانات/ودائع تلقائية.
- إرسال إشعارات SMS أو WhatsApp تلقائياً، الربط بخدمة بريد SMTP حقيقي، روابط نشر بوابات عقارية خارجية.
- خرائط تفاعلية مدفوعة داخل الموقع (يوجد رابط إحداثيات إلى خرائط جوجل عند إضافتها).
- تطبيق Flutter فعلي؛ توجد API عامة للقراءة فقط كنقطة بداية.
- تكامل MLS / IDX، ربط السجل العقاري المحلي، أو التحقق التلقائي من صحة إعلانات العقارات.
- محرر مقالات غني مدمج؛ يدعم الحقول النصية مع العرض الآمن.
- استضافة التخزين السحابي أو خدمة تحسين صور عند رفعها. الملفات تحفظ محلياً في Storage.
- نظام مدفوعات إلكتروني/عمولات متعددة الأطراف، أو إرسال عقود PDF رسمية.
- ترجمة حرة لكل البيانات؛ تُحفظ أسماء المناطق والسمات الإضافية كما أدخلها المسؤول.

## المراجعة اللازمة قبل الإطلاق العام
- تشغيل اختبارات Laravel/قاعدة البيانات فعلياً (غير ممكن ضمن بيئة إنشاء الحزمة).
- إعداد نطاق واستضافة وSSL وتخزين النسخ الاحتياطية.
- مراجعة قانونية للشركة العقارية وحقوق الصور وسياسة الخصوصية والبيانات والموافقات.
- اختبار الأداء الفعلي تحت حمل، وضبط السياسات والكوكيز والنسخ الاحتياطية.
- استبدال المحتوى/الصور/الأسعار التجريبية وجميع البيانات غير المعتمدة.
