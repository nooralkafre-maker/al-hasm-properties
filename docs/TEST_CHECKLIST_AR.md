# قائمة اختبارات التشغيل بعد Composer

- [ ] `composer install` بلا أخطاء توافق.
- [ ] `php artisan migrate:fresh --seed` على **قاعدة اختبار فقط** (يحذف البيانات الموجودة).
- [ ] `php artisan route:list` يعرض جميع المسارات.
- [ ] إنشاء مدير بأمر `php artisan alhasm:admin admin@example.com` والدخول إلى `/admin`.
- [ ] إنشاء وكيل والتحقق من عدم وصوله لإعدادات الإدارة ومنع تعديل عقارات وكيل آخر.
- [ ] إضافة عقار وصورة ومعرض صور والتأكد أن `/storage` متاح.
- [ ] تعديل/حذف العقار وتحديث الحالة والتحقق من اختفاء المسودة من الموقع وAPI.
- [ ] تصفية العقارات حسب المدينة/السعر/النوع والغرف، تجربة الترتيب والصفحات.
- [ ] حفظ العقارات في الجلسة ومشاهدة `/saved`.
- [ ] إرسال استفسار وطلب معاينة، اختبار رسائل التحقق، ومراجعة الحفظ في CRM.
- [ ] تغيير حالة العميل وإضافة ملاحظات وإسناده إلى موظف.
- [ ] إنشاء عقد وصفقة وسجل دفعات والتحقق من عرضها في الإدارة.
- [ ] نشر مقال، تحرير الصفحات، وتحديث إعدادات التواصل.
- [ ] تجربة العربية والإنجليزية والجوال والتابلت والكمبيوتر.
- [ ] اختبار sitemap.xml و robots.txt والوسوم والصور.
- [ ] اختبار 403 للزائر عند `/admin`، وCSRF، وحماية تسجيل الدخول.
- [ ] تعطيل APP_DEBUG في الإنتاج وتفعيل HTTPS.
- [ ] حذف محتوى Seed التجريبي وتحديث بيانات الشركة وشعارها والمحتوى القانوني.
