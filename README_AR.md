**المعاينة السريعة بدون تنزيل أي برامج:** افتح `OPEN_WEBSITE_DEMO.bat` لعرض الموقع، أو `OPEN_DASHBOARD_DEMO.bat` لعرض لوحة الإدارة.

**الصفحات العامة:** الرئيسية، للبيع، للإيجار، مشاريع جديدة، تفاصيل العقارات، المفضلة، من نحن، خدماتنا، فريقنا، المدونة، والتواصل.

**لوحة التحكم منفصلة تمامًا عن قائمة الموقع العام:** افتحها فقط من `OPEN_DASHBOARD_DEMO.bat`. الدخول الفعلي عبر Laravel يكون من `/login` ثم `/admin`.

**الخصائص التفاعلية المحلية:** البحث، الفلاتر، المفضلة، الاستفسارات، إضافة/تعديل/حذف عقار، المواعيد، الوكلاء، العقود، سجل المدفوعات اليدوي والتقارير. البيانات التجريبية تحفظ في المتصفح فقط.

**ملاحظة مهمة:** نسخة HTML للتصميم والتجربة المحلية، وليست Laravel العامل. لتشغيل النظام المرتبط بقاعدة البيانات تحتاج PHP 8.3+ وComposer وMySQL؛ مكتبات vendor غير مضمنة.

**الهوية:** استُخدم الشعار الأصلي الذي قدمته الشركة، والذي يتضمن عبارة Metal Supply. اعتمد شعارًا عقاريًا رسميًا عند إطلاق موقع AL HASM Properties للجمهور.

# AL HASM PROPERTIES — منصة عقارات احترافية (Laravel 13)

**محتويات الحزمة:** مشروع Laravel كامل **على مستوى الكود المصدري**، واجهة الموقع، لوحة تحكم مخصصة، قاعدة بيانات Migrations، بيانات تجريبية Seeders، صور وهوية، ترجمة عربية/إنجليزية، واجهات API للقراءة، ومعاينتان HTML لعرض التصميم دون تثبيت.

> تنبيه واضح: **هذه حزمة مصدر جاهزة للتثبيت وليست نسخة مثبتة بمجلد vendor**. يجب تشغيل `composer install` على جهاز أو خادم متصل بالإنترنت. لم تُختبر هذه النسخة باختبارات تشغيل Laravel على قاعدة بيانات فعلية ضمن بيئة إنشاء الحزمة (لا تتوافر فيها مكتبات Composer أو MySQL/PDO driver). لذلك يلزم اختبارها محلياً قبل الإطلاق. واجهات المعاينة HTML تعرض بيانات توضيحية ولا تحل محل التطبيق.

## الصفحات والوحدات

**الموقع العام:** الرئيسية، البحث والفلاتر، شراء، إيجار، على المخطط، تفاصيل العقار، معرض صور، الفيديو والجولة الخارجية، حفظ العقارات بجلسة المتصفح، استفسار العميل، طلب معاينة، صفحة اتصال، مدونة، صفحات تعريفية وقانونية، Sitemap، تصميم متجاوب، ترجمة عربية وإنجليزية RTL/LTR.

**الإدارة /admin:** إحصائيات مباشرة، إضافة/تعديل/حذف العقارات، الحالة والتسعير والصور والوكلاء، الاستفسارات/CRM، تعيين المسؤول والملاحظات، مواعيد المعاينة، العقود، سجل المدفوعات **اليدوي**، فريق العمل، المقالات، صفحات الموقع، إعدادات الاتصال، التقارير.

**مهم:** سجل المدفوعات ليس بوابة دفع، والعقود سجلات إدارة وليست مولداً قانونياً لوثائق موقعة، والتقارير تعرض بيانات قاعدة البيانات الموجودة فقط. الربط المصرفي وSMS والبريد SMTP وحلول الخرائط المدفوعة وتتبع المستندات القانوني تحتاج إعدادات/تطويراً واختباراً خاصاً قبل الإنتاج.

## 1 — متطلبات التشغيل

- PHP **8.3 فأعلى**، Composer 2.
- MySQL 8 أو MariaDB مدعومة، مع امتدادات PHP: **mbstring, openssl, PDO MySQL, ctype, curl, dom, fileinfo, tokenizer, XML** وغيرها حسب Laravel.
- Apache/Nginx موجّه إلى مجلد **public/** حصراً، أو `php artisan serve` للتجربة.
- اتصال إنترنت أثناء تنزيل Composer. الصور التجريبية مصدرها Unsplash وقد تحتاج اتصال إنترنت؛ توجد صور محلية بديلة وبعض الصور المرفقة للتصميم.

## 2 — خطوات تثبيت على جهاز أو VPS

```bash
cd AL_HASM_Properties
cp .env.example .env
composer install
php artisan key:generate
```

أنشئ قاعدة بيانات MySQL `alhasm_properties` (أو قاعدة بالاسم الذي تفضله)، ثم عدّل `.env`:

```ini
APP_NAME="AL HASM Properties"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=alhasm_properties
DB_USERNAME=YOUR_USER
DB_PASSWORD=YOUR_PASSWORD
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync
```

ثم نفّذ:

```bash
php artisan migrate
php artisan db:seed
php artisan storage:link
php artisan alhasm:admin admin@example.com
php artisan serve
```

لإجراء اختبارات PHPUnit بعد تثبيت حزم التطوير على جهازك (مع تفعيل PDO SQLite):

```bash
php artisan test
```

أدخل **اسماً وكلمة مرور قوية من 12 محرفاً فأكثر** عند طلبها لإنشاء المدير. **لا يوجد حساب مدير أو كلمة مرور افتراضيان** ضمن الكود.

- الموقع: `http://127.0.0.1:8000/`
- لوحة الإدارة: `http://127.0.0.1:8000/admin`
- تسجيل الدخول: `http://127.0.0.1:8000/login`
- معاينة الشكل دون Laravel: افتح `preview/index.html` و `preview/dashboard.html` (بيانات شكلية فقط).

> شغّل `php artisan db:seed` **مرة واحدة للعرض الأول** قبل إضافة بياناتك الحقيقية، لأنها تضبط محتوى تجريبياً وقد تعيد تحديث السجلات التجريبية عند إعادتها.

## 3 — رفع المشروع على cPanel

راجع ملف `docs/CPANEL_DEPLOYMENT_AR.md`، وباختصار: ارفع مجلد المشروع **خارج public_html**، واضبط Document Root للنطاق الفرعي على `.../AL_HASM_Properties/public`، ولا تجعل جذر المشروع متاحاً عبر الويب. فعّل PHP 8.3+ والامتدادات اللازمة، نفذ Composer/Migrations على SSH، أنشئ حساب المدير، واجعل مجلدي `storage` و`bootstrap/cache` قابلين للكتابة.

## 4 — الإنتاج والأمان

غيّر إعدادات `.env` في خادم الإنتاج:

```ini
APP_ENV=production
APP_DEBUG=false
APP_URL=https://YOUR-DOMAIN
SESSION_SECURE_COOKIE=true
LOG_LEVEL=warning
```

ثم:

```bash
php artisan optimize:clear
php artisan config:cache
php artisan view:cache
php artisan route:cache
```

اختبر تسجيل الدخول والصلاحيات، رفع صور العقارات، إرسال الاستفسارات، التخزين، وفتح الروابط. استخدم HTTPS ونسخاً احتياطية منتظمة واختبارات تحمل. لا تشارك ملف `.env` أو مجلد `vendor` عبر موقع مفتوح.

## 5 — الشعار والمحتوى التجريبي

- الصورة الأصلية للشعار: `public/assets/img/original-company-logo.png`، وهي مأخوذة من الصورة المرسلة وتحتوي عبارة **Metal Supply** كما هي؛ لم يتم اختراع شعار عقاري رسمي. استبدلها بنسخة عقارية معتمدة إذا كانت الهوية القانونية مختلفة.
- **جميع العقارات والصور والأسعار والمواد القانونية الموضوعة عبر Seeder تجريبية غير حقيقية**؛ لا تعرضها للجمهور كعقارات متاحة حتى يتم حذفها أو استبدالها بمعلومات موثقة.
- أرقام الهاتف والبريد الإلكتروني فارغة أو تجريبية؛ عدّلها من لوحة الإعدادات بعد تثبيت الموقع.
- محتوى الصفحات القانونية عينات ويحتاج مراجعة قانونية خاصة بنشاط الشركة في الإمارات قبل الإطلاق.

## 6 — التنظيم

```text
AL_HASM_Properties/
├── app/
│   ├── Http/Controllers/{Admin,Auth}/   # تحكم الموقع والإدارة والمصادقة
│   ├── Http/Middleware/               # الصلاحيات واللغة
│   └── Models/                        # العقارات والعملاء والعقود ...
├── bootstrap/                          # تشغيل Laravel
├── config/                             # إعدادات النظام
├── database/{migrations,seeders}/      # تصميم قاعدة البيانات ومحتوى تجريبي
├── public/assets/{css,js,img}/         # ملفات الواجهة والصور
├── resources/views/{admin,auth,layouts,partials,site}/
├── lang/ar.json                        # الترجمة العربية
├── routes/{web,api,console}.php
├── preview/{index,dashboard}.html      # تصميم للمعاينة فقط
├── docs/                               # التوثيق
├── composer.json
└── .env.example
```
